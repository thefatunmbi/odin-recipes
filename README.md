# 🍽️ Odin Recipes

This project is part of The Odin Project curriculum.
It is a simple recipe website built using only HTML.

## 📌 About the Project

The website contains a homepage with links to different recipe pages.
Each recipe page includes an image, description, ingredients, and step-by-step instructions.

## 🛠️ Skills Demonstrated

* HTML structure (headings, paragraphs, lists, links, images)
* Working with relative links between pages
* Organizing files and folders in a project
* Using Git and GitHub for version control
